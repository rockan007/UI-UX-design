# UI/UX 审查清单

用于让 Claude Code 在修改前或修改后审查页面。建议每次页面优化后都执行一次。

## 审查 Prompt

```text
请以资深 UI/UX 设计师的角度审查当前页面。
只指出具体问题，不要泛泛而谈。

请按严重程度输出：
1. 影响用户完成任务的问题
2. 信息层级问题
3. 视觉一致性问题
4. 表单或表格体验问题
5. 移动端问题
6. 可访问性问题

然后修复这些问题。
不要改业务逻辑。
```

## 信息层级

- 页面标题是否清楚
- 用户是否知道当前页面的用途
- 主信息是否比次要信息更突出
- 主操作是否容易被发现
- 页面是否存在多个互相竞争的重点

## 操作体验

- 主要操作是否在合理位置
- 次要操作是否被弱化
- 危险操作是否有确认
- 操作完成后是否有反馈
- 用户是否容易撤销或返回

## 视觉一致性

- 按钮尺寸是否一致
- 输入框高度是否一致
- 表格行高是否一致
- 状态标签样式是否统一
- 模块间距是否稳定
- 圆角和阴影是否克制

## 表单体验

- label 是否清楚
- 必填项是否明确
- 错误提示是否靠近字段
- 帮助文本是否必要且简短
- 提交按钮是否清楚
- 保存成功或失败是否有反馈

## 表格和列表

- 高频字段是否靠左
- 状态是否容易识别
- 操作列是否固定在合理位置
- 空状态是否有意义
- 加载状态是否不会导致布局跳动
- 移动端是否仍然可读

## 移动端

- 是否出现横向挤压
- 是否有文字溢出
- 是否有元素重叠
- 按钮点击面积是否足够
- 筛选、菜单、弹窗是否可用
- 表格是否有移动端方案

## 可访问性

- 键盘 focus 是否可见
- 颜色对比度是否足够
- 图标按钮是否有语义
- 错误状态是否不只依赖颜色
- 表单控件是否有 label
