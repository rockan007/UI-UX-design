# UI/UX 审查清单

本文件用于页面生成后的质量检查。Claude Code 完成页面后，应按本清单审查并修复问题。

## 审查 Prompt

```text
请以资深 UI/UX 设计师的角度审查当前页面。
只指出具体问题，不要泛泛而谈。

请按严重程度输出：
1. 影响用户完成任务的问题
2. 信息层级问题
3. 视觉一致性问题
4. 表单或表格体验问题
5. 移动端问题
6. 可访问性问题

然后修复这些问题。
不要改业务逻辑。
```

## 任务完成路径

- 用户是否知道当前页面是什么
- 用户是否知道下一步能做什么
- 主操作是否明显
- 次要操作是否不会干扰主操作
- 危险操作是否有确认

## 信息层级

- 页面标题是否清楚
- 关键数据是否优先展示
- 说明文本是否简短
- 状态信息是否容易识别
- 页面是否有过多视觉重点

## 视觉一致性

- 按钮样式是否统一
- 表单控件高度是否统一
- 表格行高是否一致
- 标签样式是否统一
- 间距是否稳定
- 圆角和阴影是否克制

## 表单体验

- 字段顺序是否合理
- 必填项是否明确
- 错误提示是否靠近字段
- 提交反馈是否明确
- 提交中是否防止重复提交
- 移动端输入是否顺畅

## 表格体验

- 高频字段是否靠左
- 操作列是否清晰
- 筛选区是否紧凑
- 批量操作是否明确
- 空状态是否提供下一步
- 移动端是否仍可管理数据

## 状态反馈

- loading 是否明确
- empty 是否有说明和下一步
- error 是否可重试
- success 是否有反馈
- disabled 是否可识别
- permission denied 是否清楚

## 响应式

- 1440px 是否布局合理
- 1024px 是否不拥挤
- 768px 是否减少复杂分栏
- 390px 是否无文字溢出和元素重叠
- 移动端主操作是否可见

## 可访问性

- 键盘 focus 是否可见
- 图标按钮是否有可访问名称
- 文本对比度是否足够
- 错误状态是否不只依赖颜色
- 点击目标是否足够大
