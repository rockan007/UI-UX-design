# 单页面 UI/UX 优化 Prompt

把下面 Prompt 复制给 Claude Code，并替换页面路径和页面目标。

```text
请只从 UI/UX 角度优化页面：{页面路径}

页面目标：
{说明这个页面用户最重要的任务}

工作边界：
- 不要改业务逻辑
- 不要改接口协议
- 不要改数据库结构
- 不要重构无关代码
- 优先使用现有组件和样式系统

请先阅读相关文件，理解当前页面结构和组件来源。
然后从以下角度优化：

1. 信息层级
- 用户打开页面后是否能立刻知道这是哪里
- 最重要的信息是否优先展示
- 次要信息是否被弱化

2. 操作路径
- 主操作是否明显
- 次要操作是否不会干扰主操作
- 危险操作是否有确认或明确警示

3. 布局和间距
- 页面是否拥挤
- 模块之间是否有稳定间距
- 桌面端是否充分利用空间
- 移动端是否自然堆叠

4. 表单体验
- 字段顺序是否合理
- 必填、错误、帮助信息是否清楚
- 提交、取消、保存反馈是否明确

5. 数据展示
- 表格或列表是否易扫描
- 状态、时间、金额、数量等字段是否容易识别
- 操作列是否稳定

6. 交互状态
- loading
- empty
- error
- success
- disabled
- hover
- focus
- validation error

7. 响应式
- 检查 1440px、1024px、390px
- 不允许文字溢出
- 不允许元素重叠
- 不允许移动端主要操作不可见

完成后请：
1. 说明你发现的 UI/UX 问题
2. 说明你做了哪些修改
3. 运行必要检查
4. 如果项目支持浏览器预览，请截图检查并修复明显问题
```

## 后台列表页专用补充

```text
这是后台高频使用的列表页，请额外关注：
- 筛选区是否紧凑
- 表格是否易扫描
- 批量操作是否清楚
- 操作列是否过多
- 空状态是否提供下一步操作
- 移动端是否可用
```

## 表单页专用补充

```text
这是表单页，请额外关注：
- 字段分组是否合理
- 必填项是否清楚
- 错误提示是否靠近字段
- 保存前后反馈是否明确
- 取消、返回、保存草稿等操作是否清楚
- 移动端输入体验是否顺畅
```

## 详情页专用补充

```text
这是详情页，请额外关注：
- 关键信息是否在首屏可见
- 状态和主要操作是否明显
- 详情信息是否有清楚分组
- 历史记录、日志、备注等次要信息是否不会干扰主线
- 返回列表和继续操作是否方便
```
