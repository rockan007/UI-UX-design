# O2M Sub-Form — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- []`) syntax for tracking.

**Goal:** Upgrade order items from single text input to multi-field O2M sub-form with name, spec, quantity, unit price, and auto-calculated subtotal.

**Architecture:** Expand OrderItem interface with spec/quantity/unitPrice fields. Replace single-input rows with 6-column grid (column headers + data rows). Add `itemSubtotal()` computed per row. Update mock data structure in OrderManageView.

**Tech Stack:** Vue 3 + Element Plus + Tailwind CSS + vue-i18n
