# 交互规则

组件交互行为规则。每个组件都必须具有适当的交互状态——不允许静态、非交互式的组件。

## 通用

- 交互元素：`cursor: pointer` + 悬停视觉变化（`duration-fast` 150ms）。
- 非交互元素：无悬停效果（避免错误的可供性暗示）。
- 聚焦环：`2px solid` brand-600，`outline-offset: 2px`，键盘导航时可见。
- **禁用：** `opacity: 0.5` + `cursor: not-allowed` + 忽略点击/键盘事件。绝不能仅依赖颜色来传达状态。
- **加载中：** 骨架屏或加载动画；无布局偏移。
- **过渡：** 悬停/聚焦 150ms，切换 200ms，对话框/抽屉 300ms。

> 适用：两者

### 确认模式

对破坏性、不可逆或影响范围广泛的操作使用确认。

- 确认必须包含：操作名称、受影响的项或数量、后果、破坏性确认按钮、安全取消选项。
- 避免对无害的可逆操作使用确认。
- 破坏性操作按钮使用 `type="danger"`。

> 适用：管理后台为主

### 连接线与圆角

**规则：** 当容器在一侧有可见的连接线时（时间轴竖线、步骤连接线、分支线），该侧的圆角必须为 `0`。圆角会破坏连接线的视觉连续性。

| 连接线侧 | CSS |
|---|---|
| 左边框 | `border-l-*` + `rounded-l-none` |
| 右边框 | `border-r-*` + `rounded-r-none` |
| 上边框 | `border-t-*` + `rounded-t-none` |
| 下边框 | `border-b-*` + `rounded-b-none` |

不要对使用 `border-l-*` / `border-r-*` 作为连接线的容器应用统一的 `rounded-*`。
改用方向性圆角：左侧连接线使用 `rounded-r-btn`，右侧连接线使用 `rounded-l-btn`。

> 适用：两者

## 卡片

### 可点击卡片
- 悬停：`shadow-sm → shadow-md`，`border-neutral-200 → brand-200`。
- `cursor: pointer`。
- 内部按钮使用 `@click.stop` 防止事件冒泡。

### 仅展示卡片
- 无悬停效果，`cursor: default`。
- 不要添加无意义的卡片级点击。

> 适用：前端为主；管理后台指标卡片可使用可点击卡片悬停效果。

## 表格

### 数据行
- 悬停：`background: neutral-50`（`#f5f5f5`）。
- 可点击行：`cursor: pointer`。
- 选中行：`background: brand-50`（`#eff6ff`）+ 左侧 `2px solid` brand-600。

### 表头
- 可排序：悬停颜色变化 + 点击切换排序图标（升序/降序/无）。
- 不可排序：`cursor: default`。
- 排序状态必须在视觉上有明显区分。

### 分页
- 当前页：高亮背景。
- 页码按钮悬停：`background: neutral-100`。
- 禁用按钮（首页/末页）：禁用状态。

> 适用：管理后台为主。

### 操作按钮

表格操作列中的纯图标操作按钮：

- 悬停：提示框 300ms 后出现（`:show-after="300"`），无隐藏延迟（`:hide-after="0"`）。
- 位置：`top`，避免遮挡相邻的表格行。
- 最小点击区域：28×28px（默认适用于 `el-button size="small" :icon`）。
- 破坏性操作（删除）：`type="danger"`。
- 主要/查看操作：`type="primary"`。
- 其他操作：默认 `link` 样式。
- 每个按钮必须通过 `el-tooltip content` 提供无障碍标签。

## 图表

### 柱状图
- 柱悬停：亮度变化（`filter: brightness(0.9)`）+ 带精确值的提示框。
- 提示框：200ms 延迟，内容 = "标签 + 值 + 单位"，离开时消失。
- 可点击的数据点：`cursor: pointer`。

### 间距与形状

- **间隙与柱的比例：** 柱之间的间隙应为柱宽的 50%–100%。默认约为 50%（柱宽 = 间隙的 2 倍）。
- **柱宽固定**——不要使用 `flex-1` 将柱拉伸以填满整个容器。
- **仅使用平直的柱顶。** 绝不要在柱状图柱体上使用 `rounded-t-*`。顶部边缘必须是精确的视觉端点。
- 柱宽相对于间隙过宽（比例 > 4:1）会在视觉上失衡，失去离散数据点的节奏感。

### 折线图
- 数据点悬停：圆点放大 + 提示框。
- 折线本身不响应悬停。

### 空数据
- 显示空状态（"暂无数据"），而非空白区域。
- 可选：引导用户添加数据。

> 适用：管理后台仪表盘。

## 表单

### 验证
- **时机：** 当前字段失焦时验证；提交时进行完整验证。
- 验证过程中不要阻止用户输入。

### 提交
- 提交按钮立即进入加载中 + 禁用状态。
- 必须防止重复提交（前端节流 + 后端幂等）。
- 成功：Toast 反馈，2 秒自动消失，或内联成功状态。
- 失败：恢复按钮为可点击状态，显示错误信息。

### 错误展示
- 放置在对应字段附近。
- 红色文本（`danger` `#dc2626`）+ 红色输入框边框 + 错误图标。
- 绝不能仅使用颜色来传达错误。

### 必填字段
- 标签后加红色星号（`*`）。
- 可选：非必填字段使用"(选填)"标记。

> 适用：两者。

## 导航

### 侧边栏
- 激活项：`bg-brand-50 + text-brand-600 + font-medium`。
- 非激活悬停：`bg-neutral-50`。
- 激活和聚焦状态必须可见。
- 折叠/展开：200ms 过渡。
- 折叠状态：`overflow-x: hidden` 以裁剪溢出内容并防止水平滚动条。

### 标签页

- 选中：底部 `2px` 边框 + `brand-600` 文字 + `font-weight: 500`
- 悬停：文字变为 `brand-600`
- 切换标签页时无内容跳动——面板即时渲染
- 切换标签页时不触发验证——标签页之间可自由导航
- 激活标签页状态是本地组件状态（`ref<string>`），而非 URL/路由中的状态
- 切换时滚动位置重置到标签页面板顶部

**表单中的标签栏：**

- 标签栏位于工具栏和表单内容之间，使用 `<el-tabs v-model="activeTab" tab-position="top">`
- 所有标签页始终可见——无水平滚动或"更多"下拉菜单。如果标签页过多，应重新组织表单结构，而非添加滚动。
- 至少需要 2 个标签页才渲染标签栏；少于 2 个 = 无标签页（仅使用分区卡片）

**一对多/多对多标签页徽章：**

- 在标签页标签插槽中使用 `<el-badge :value="items.length" :hidden="items.length === 0">`
- 非激活标签页徽章：`var(--neutral-400)` 背景色
- 激活标签页徽章：`var(--brand-600)` 背景色
- 数量为 0 时不显示徽章

**隐藏标签页上的验证错误：**

- 单次提交验证所有标签页，而不仅仅是当前可见的标签页
- 如果隐藏标签页上存在验证错误：
  - 提交失败
  - 自动切换到第一个有错误的标签页
  - 错误标签页标签变为红色（`var(--el-color-danger)`），并显示 `WarningFilled` 图标
  - 错误标签页上的 `<el-badge>` 切换为 `type="danger"`
- 用户修复错误并重新提交后，错误指示器清除

**移动端标签页：**

- 视口 < 768px 时，标签页完全折叠——无标签栏、无下拉菜单
- 标签栏：`hidden md:block`
- 所有分区卡片以扁平垂直布局渲染，使用 `gap-4`
- 这匹配当前的非标签页移动端布局行为

### 面包屑
- 最后一项（当前页面）：不可点击，`color: neutral-950`。
- 前面的项：可点击，悬停 `color: brand-600`。
- 分隔符不可交互。

> 适用：两者。

## 适用性索引

| 组件 | 前端 | 管理后台 |
| --- | --- | --- |
| 可点击卡片 | 主要使用 | 指标卡片悬停可用 |
| 展示卡片 | 内容展示 | 数据卡片 |
| 表格 | 不常用 | 主要使用 |
| 图表 | 不常用 | 仪表盘 |
| 表单验证 | 简化版 | 完整版 |
| 侧边栏 | 可选 | 标准配置 |
| 标签页 | 内容分类、表单分区 | 功能切换、管理后台表单标签页 |
