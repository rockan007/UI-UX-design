# 设计令牌

所有视觉属性的精确值。不得猜测颜色、间距或字体大小。

| --- | --- | --- |
| `neutral-50` | `#fafafa` | 页面背景 |
| `neutral-100` | `#f5f5f5` | 表面背景 |
| `neutral-200` | `#e5e5e5` | 边框 |

| `neutral-800` | `#262626` | 次要文字 |
| `neutral-950` | `#0a0a0a` | 主要文字 |

### 规则

- 品牌色仅用于主要操作、选中状态和关键反馈。
- 危险色仅用于破坏性操作。
- 不得使用大面积渐变或荧光背景。

## 排版

| 令牌 | 字号 | 行高 | 用途 |
| --- | --- | --- | --- |
| `text-xs` | `12px` | `16px` | 表格单元格（管理后台）、帮助文字、徽章 |
| `text-sm` | `13px` | `20px` | 次要信息、时间戳、标签 |
| `text-base` | `15px` | `22px` | 正文（管理后台可使用 14px） |
| `text-lg` | `16px` | `24px` | 表格标题、侧边栏分区 |
| `text-xl` | `20px` | `28px` | 卡片标题、表单分区标题 |
| `text-2xl` | `24px` | `32px` | 管理后台页面标题、前端分区标题 |
| `text-3xl` | `30px` | `36px` | 前端页面标题（不用于管理后台） |

### 字重

- 标题：`600` 或 `700`
- 正文：`400`
- 强调：`500`
- 不得使用负字间距。
- 不得使用视口宽度字体缩放。

## 强调色条

管理后台中的统计/指标卡片使用 3px 左侧边框色条来区分数据类别：

| 颜色 | 值 | 语义 | 示例指标 |
| --- | --- | --- | --- |
| 蓝色 | `#2563eb` | 中性/正向 | 用户、流量、系统关键绩效指标 |
| 青色 | `#0891b2` | 流转/进行中 | 订单、交易、处理中 |
| 琥珀色 | `#d97706` | 需关注 | 收入、财务、待处理项、警告 |
| 绿色 | `#16a34a` | 正向/已完成 | 完成率、成功率、增长 |
| 紫色 | `#7c3aed` | 关联关系（O2M/M2M） | 子记录、关联实体 |

用法：`border-left: 3px solid {color}` + 其余边使用标准卡片边框。

分区标题颜色与色条颜色匹配：蓝色用 `text-blue-700`，青色用 `text-cyan-700`，
紫色（关联关系）分区用 `text-purple-700`。在管理后台表单中，一对多/多对多子表单分区
卡片使用紫色强调色条，以视觉上区分关联字段与实体字段。

## 阴影

### 叠加阴影（对话框、抽屉、下拉菜单）

| 级别 | 值 | 用途 |
| --- | --- | --- |
| `shadow-sm` | `0 1px 2px rgba(0,0,0,0.04), 0 1px 3px rgba(0,0,0,0.06)` | 下拉菜单、提示框 |
| `shadow-md` | `0 4px 6px rgba(0,0,0,0.04), 0 2px 4px rgba(0,0,0,0.06)` | 对话框、弹出框 |
| `shadow-lg` | `0 10px 15px rgba(0,0,0,0.06), 0 4px 6px rgba(0,0,0,0.06)` | 抽屉、侧边面板 |

### 容器阴影（仅限管理后台图表面板）

`shadow-sm` 也可用于图表容器和数据可视化面板，产生与数据表格不同的凸起效果。统计/指标卡片、表格、表单和列表容器不得使用阴影。

除上述图表容器外，卡片、表格、表单或内容区域均不得使用装饰性阴影。

## 动画

### 持续时间

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `duration-fast` | `150ms` | 悬停、聚焦 |
| `duration-base` | `200ms` | 切换、淡入淡出 |
| `duration-slow` | `300ms` | 对话框、抽屉 |

### 缓动

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `ease-default` | `ease-out` | 入场动画 |
| `ease-expressive` | `cubic-bezier(0.16, 1, 0.3, 1)` | 前端弹性效果 |

**管理后台：仅使用 `ease-default`，不得使用弹性缓动。** 前端：弹性效果允许用于主视觉/首屏区域。
